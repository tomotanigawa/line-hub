# 仕事のやること

クライアントとの連絡から出た「オーナーがやること」と「決まった予定」を、Slack のスレッドに埋もれさせずに残す台帳。
家族の予定など仕事以外のものは入れない。

## レコードの形

- `id` — `todo-<YYYYMMDDHHmmss>-<4桁>`。ファイル名そのもの
- `title` — やること（必須）。「◯◯を送る」「◯◯を確認する」のように動詞で終える
- `client` — 取引先名（例 A社）
- `kind` — Todo（やること）/ 予定（日時の決まった打合せ・撮影・納品）
- `due` — 期限（Todo）または当日（予定）。`YYYY-MM-DD`。未定なら空
- `time` — 予定の時刻（例 `14:00-15:00`）
- `status` — 未着手 / 対応中 / 先方待ち / 完了 / 見送り。カンバンの列
- `priority` — 高 / 中 / 低。**高だけ** `due` の前日にベル通知が出る
- `source` — どこから来たか（LINE / Slack / Gmail / 電話 / その他）
- `link` — 受付チャンネル #ai-desk のスレッドURL（元のやりとりに戻れる）
- `place` — 場所
- `memo` — 補足

## 書き足すとき

- 同じ取引先で、同じ中身の未完了レコードがあれば新しく作らず、そのレコードの `memo` に追記する
- 先方の返事待ちになったら `status` を「先方待ち」にする（完了にはしない）
